Deep Learning Foundations

Deep learning systems solved problems that were considered hard prior to 2010, e.g. obtaining superhuman / SOTA scores on tasks and challenges such as ImageNet, CASP, and Go (board game)1. Later, in the early 2020s, unprecedented progress in text & image generation were made with models like GPT-3 and Stable Diffusion:


About This Series

This series builds the mathematical and computational foundations of deep learning from scratch — in pure Python and PyTorch, deriving everything from first principles.

Audience. Someone comfortable with Python, NumPy, and basic calculus who wants to understand how neural networks actually work before moving on to language models. A mathematics background is assumed — derivations are shown in full, not waved away. Code is the other half of the explanation.

Stack. Pure Python and PyTorch. No high-level training frameworks. Every concept is grounded in code you write yourself. The core series (01–09) covers the full story from a single linear classifier through multi-layer networks, automatic differentiation, modern optimizers, CNNs, RNNs, and the Transformer encoder. Advanced Topics (NB13–17) apply the foundations to real tasks and architectures. This provides a minimal prerequisite foundation for the Language Models from Scratch series.

Prerequisites

  • Python 3.10+, PyTorch 2.0+, NumPy, Matplotlib
  • Linear algebra (matrix products, eigenvalues), calculus (chain rule, partial derivatives). Derivations are shown in full.
  • Most notebooks run on CPU. Notebook 06 (CNNs) includes ResNet fine-tuning on a real image dataset — a GPU (e.g. T4) is strongly recommended for that section.

How to Read This Series

If you’re new to deep learning: Work through 01 → 05 in order — they build directly on each other. On a first pass through 05, focus on the results rather than every experiment; the code is extensive.

If you want the full picture: Continue with 06 → 07 → 08 → 09 to go from CNNs through language models, RNNs, and Transformers. The appendices are optional enrichment — NB11 for approximation theory, NB12 for CNN architecture depth, NB18 for the double descent phenomenon and why the classical bias-variance story is incomplete.

If you want applied practice: After 09, work through the Advanced Topics (13–17) to see the foundations applied to translation, generative models, diffusion, segmentation, and captioning.

Next steps: After the core notebooks, continue with Language Models from Scratch.
